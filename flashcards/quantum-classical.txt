What is a "shot" in quantum computing?	One full run of a circuit ending in measurement; it yields one bitstring sampled from the output distribution.
Mean and variance of a Bernoulli(p) variable?	Mean p, variance p(1 − p).
Standard error of a probability estimated from N shots?	SE = √(p̂(1 − p̂)/N); 95% interval ≈ p̂ ± 1.96·SE.
How many more shots to halve a statistical error bar?	Four times as many, because the error scales as 1/√N.
Shots needed for a ±0.01 95% half-width in the worst case p = ½?	N = (1.96 × 0.5 / 0.01)² = 9,604.
How is ⟨Z⟩ related to the probability of outcome 0?	⟨Z⟩ = P(0) − P(1) = 2P(0) − 1; its standard error is twice that of P(0).
State Bayes' rule with the law of total probability in the denominator.	P(A|B) = P(B|A)P(A) / [P(B|A)P(A) + P(B|not A)P(not A)].
When does the normal-approximation interval for p̂ fail?	When Np̂ or N(1 − p̂) is small, e.g. zero counts; use a Wilson or Clopper–Pearson interval.
Which character of a Qiskit bitstring is qubit 0?	The rightmost one: Qiskit prints bitstrings little-endian.
What is the test for independence of two measurement outcomes?	P(x, y) = P(x)·P(y) for every pair of outcomes x, y.
How many Boolean functions of n input bits (one output) are there?	2^(2^n): 16 for n = 2, 256 for n = 3.
How do you make NOT, AND and OR from NAND?	NOT a = NAND(a,a); AND = NOT(NAND(a,b)); OR(a,b) = NAND(NOT a, NOT b).
Define circuit size and circuit depth.	Size: number of gates. Depth: number of gates on the longest input-to-output path.
What makes a classical gate reversible?	It is a bijection on bitstrings: every output comes from exactly one input, so inputs can be recovered.
Toffoli gate action on bits (a, b, c)?	(a, b, c ⊕ a·b): the target flips only when both controls are 1.
Fredkin gate action on bits (a, b, c)?	If a = 1 swap b and c; otherwise do nothing. It conserves the number of 1s.
How do you get NAND from a Toffoli gate?	Set the target to 1: the output is 1 ⊕ a·b = NAND(a, b).
What is the matrix of a reversible classical gate?	A permutation matrix: one 1 in every row and column; it satisfies PᵀP = I, so it is unitary.
State Landauer's principle.	Erasing one bit releases at least k_B T ln 2 of heat; about 2.87 × 10⁻²¹ J (0.0179 eV) at 300 K.
Who first verified Landauer's bound experimentally, and how?	Bérut et al., Nature 2012: a colloidal particle in a double-well optical trap.
What is Bennett's uncompute trick?	Compute keeping garbage, copy the answer with CNOTs, then run the computation backwards to reset the garbage to 0.
What is the standard reversible oracle for a function f?	U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩; it is its own inverse.
Why must quantum gates be reversible?	Closed-system evolution is unitary (U†U = I), so every gate has an inverse; only measurement is irreversible.
Formal meaning of f(n) = O(g(n))?	There exist c > 0 and n₀ with f(n) ≤ c·g(n) for all n ≥ n₀.
What is the input size of an integer N in complexity theory?	Its bit length n ≈ log₂ N; so √N = 2^(n/2) is exponential in n.
Define NP.	Decision problems whose yes-instances have polynomial-length certificates checkable in polynomial time.
What makes a problem NP-complete?	It is in NP and every NP problem reduces to it in polynomial time. SAT was first (Cook 1971).
Define BPP.	Problems solvable in polynomial time by a randomised algorithm that is correct with probability ≥ 2/3 on every input.
Which chain of inclusions involving BQP is proven?	P ⊆ BPP ⊆ BQP ⊆ PP ⊆ PSPACE.
Is P ≠ NP proven?	No. It is open (a Clay Millennium Prize Problem) and widely believed.
Which separation is proven by the time hierarchy theorem?	P ≠ EXP.
Why would proving BPP ≠ BQP be a huge result?	Since BQP ⊆ PSPACE, it would also prove P ≠ PSPACE, a major open problem.
Where does factoring sit, as far as is proven?	NP ∩ coNP and BQP (Shor). Not known to be in P; believed not NP-complete.
Heuristic running time of the general number field sieve?	exp((64/9)^(1/3) (ln N)^(1/3) (ln ln N)^(2/3) (1 + o(1))): sub-exponential.
Query complexity of unstructured search, classical vs quantum?	Classical Θ(N); quantum Θ(√N), about (π/4)√N (Grover; optimal by BBBV 1997).
What does Beals et al. (2001) say about total Boolean functions?	Deterministic and quantum query complexity are polynomially related: D(f) = O(Q(f)⁶).
Which problem gave the first exponential quantum vs randomised query separation?	Simon's problem (hidden XOR mask), the ancestor of Shor's period finding.
