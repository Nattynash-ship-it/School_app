Shannon entropy of a distribution p(x)?	H(X) = −∑ p(x) log2 p(x), in bits, with 0·log 0 = 0. Average information per symbol = best compression rate.
Binary entropy h(p)?	h(p) = −p log2 p − (1−p) log2(1−p). h(1/2) = 1, h(0.75) = 0.8113, h(0.9) = 0.4690.
Maximum Shannon entropy for d outcomes?	log2 d, reached only by the uniform distribution.
von Neumann entropy S(ρ)?	S(ρ) = −Tr(ρ log2 ρ) = −∑ λi log2 λi, the Shannon entropy of the eigenvalues of ρ.
Range of S(ρ) for n qubits?	0 ≤ S(ρ) ≤ n bits: 0 exactly for pure states, n exactly for the maximally mixed state I/2^n.
Does a unitary gate change S(ρ)?	No. S(UρU†) = S(ρ) because unitaries preserve eigenvalues.
Quick eigenvalues of a 2×2 density matrix?	λ = (1 ± √(1 − 4 det ρ))/2, since the eigenvalues sum to Tr ρ = 1 and multiply to det ρ.
S of ρ = (3/4)|0⟩⟨0| + (1/4)|+⟩⟨+|?	Eigenvalues 0.8953 and 0.1047, so S = 0.4838 bits, less than h(3/4) = 0.8113 because the states overlap.
Why is the entropy of the diagonal of ρ the wrong answer?	S uses eigenvalues. The diagonal gives the entropy of a Z-basis measurement, which is ≥ S(ρ) and equal only if ρ is diagonal.
Entropy of entanglement of a pure state |ψ⟩AB?	E(ψ) = S(ρA) = S(ρB), the entropy of the squared Schmidt coefficients. Unit: ebits; a Bell state has 1 ebit.
Entropy of entanglement of cos(π/6)|00⟩ + sin(π/6)|11⟩?	ρA = diag(3/4, 1/4), so E = h(0.75) = 0.8113 ebits.
Subadditivity of von Neumann entropy?	S(A,B) ≤ S(A) + S(B), with equality iff ρAB = ρA ⊗ ρB.
Araki–Lieb inequality?	S(A,B) ≥ |S(A) − S(B)|.
Quantum conditional entropy and its surprise?	S(A|B) = S(A,B) − S(B). It can be negative: −1 for a Bell state. Negative values imply entanglement.
Quantum mutual information I(A:B)?	I(A:B) = S(A) + S(B) − S(A,B) ≥ 0. Up to 2 bits for two qubits (Bell state); classical bits reach at most 1.
Strong subadditivity?	S(A,B,C) + S(B) ≤ S(A,B) + S(B,C). A deep theorem underlying quantum Shannon theory.
Holevo quantity χ of an ensemble {px, ρx}?	χ = S(∑ px ρx) − ∑ px S(ρx). For pure signals χ = S(ρ̄).
Holevo bound chain?	I(X:Y) ≤ I_acc ≤ χ ≤ H(X), and χ ≤ log2 d, so n qubits carry at most n classical bits.
χ for |0⟩ or |+⟩ with probability 1/2 each?	ρ̄ eigenvalues 0.8536 and 0.1464, so χ = 0.6009 bits. The best single projective measurement gets 0.3991 bits.
Accessible information I_acc?	The maximum over all measurements (POVMs) of the mutual information I(X:Y) between Alice's letter and Bob's outcome.
Is χ achieved by a single measurement?	Not in general. χ is an upper bound and the asymptotic rate achievable with block coding (Holevo–Schumacher–Westmoreland).
χ for the four BB84 states sent with equal probability?	ρ̄ = I/2 so χ = 1 bit, not 2: more states per qubit never beat 1 bit per qubit.
How does dense coding respect the Holevo bound?	Bob decodes 2 bits from 2 qubits: the one Alice sends plus his half of a pre-shared Bell pair. 1 qubit + 1 ebit ≥ 2 bits.
What does LOCC stand for and what can it never do?	Local operations and classical communication. It can never create entanglement from separable states.
Separable two-party state?	ρAB = ∑ pi ρA(i) ⊗ ρB(i). Any state not of this form is entangled.
Concurrence of a pure two-qubit state a|00⟩ + b|01⟩ + c|10⟩ + d|11⟩?	C = 2|ad − bc|. 0 for product states, 1 for Bell states.
Wootters concurrence for a mixed two-qubit ρ?	ρ̃ = (Y⊗Y)ρ*(Y⊗Y); λ's = square roots of eig(ρρ̃), decreasing; C = max(0, λ1 − λ2 − λ3 − λ4).
Entanglement of formation from concurrence?	E_F = h((1 + √(1 − C²))/2). C = 0.4 gives 0.2502 ebits; C = 0.6 gives 0.4690 ebits.
Concurrence of p|Φ⁺⟩⟨Φ⁺| + (1 − p)I/4?	C = max(0, (3p − 1)/2). Entangled iff p > 1/3; at p = 0.6, C = 0.4.
Peres–Horodecki (PPT) test for two qubits?	ρ is entangled iff its partial transpose has a negative eigenvalue. For p = 0.6 Werner: eigenvalues −0.2, 0.4, 0.4, 0.4.
CKW monogamy inequality for three qubits?	C_AB² + C_AC² ≤ 4 det ρA. If A is maximally entangled with B, C_AC = 0.
Pairwise concurrences of GHZ and W states?	GHZ: C_AB = C_AC = 0 (entanglement is three-way). W: C_AB = C_AC = 2/3, and 4/9 + 4/9 = 8/9 = 4 det ρA.
What is entanglement distillation?	An LOCC protocol turning many noisy entangled pairs into fewer, higher-fidelity pairs. Best asymptotic yield = distillable entanglement E_D.
One round of recurrence distillation?	Twirl to Werner form, bilateral CNOT pair 1 → pair 2, measure pair 2 in Z on both sides, keep pair 1 if results agree.
When does a recurrence round improve Werner fidelity F?	When F > 1/2. Example: F = 0.7 gives F' = 0.7353 with success probability 0.68.
Can every entangled state be distilled?	Every entangled two-qubit state can. In larger systems some entangled (bound entangled) states cannot.
Resource count for teleportation?	1 ebit + 2 classical bits → 1 qubit transferred.
Resource count for entanglement swapping?	Ebits A–R and R–B, a Bell measurement at R and 2 classical bits → 1 ebit between A and B.
